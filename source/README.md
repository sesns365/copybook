# 直式生字學習單製作工具

由「生字書寫練習網」抽出的獨立學習單製作工具（純前端靜態網站，不需資料庫或登入）。

## 兩種模式
- **簡易模式**（預設）：選課次 → 勾語詞 → 選練習方式 → 下載 PDF／列印。同一語詞有兩個生字時合併成一組，兩個字都練習。
- **進階模式**：拖曳排版、逐字逐格調整、儲存多份學習單；可從簡易模式一鍵帶入細調。

## 功能
- 南一、康軒、翰林一至六年級上學期課次語詞
- 直式生字本：由上往下書寫、由右往左換欄
- 描紅、描灰、空白、部件提示可逐字逐格設定；批次套用第 1、2…次提示
- 拖曳排版、A4／A3、字格 15／20／25／30 mm、注音、十字線濃淡
- 下載 Word（.docx）與 PDF
- 學習單設定存在瀏覽器（localStorage），可下載／匯入備份檔（.json）

原網站需要學生名單的「分組差異化批次輸出」未納入。

## 使用
- 直接部署：把 `dist/` 資料夾整個上傳到 GitHub Pages、Netlify 或任何靜態網站空間即可（支援子路徑）。
- 注意：需透過網址（http/https）開啟，直接雙擊 `index.html` 會讀不到筆畫資料。
- 本機測試：`npm install` → `npm run dev`；重新建置：`npm run build`。

## 單一 HTML 檔
執行 `node build-single.mjs` 會產生「直式生字學習單製作工具.html」（約 9 MB），筆畫資料已壓縮內嵌，雙擊即可離線使用。

## 字型

網頁上的楷書字型由 `font-src/moe-standard-kai-5.1.ttf` 切成 `public/fonts/kai/` 的多個 woff2 小檔（依字最早出現的年級分組），瀏覽器只下載畫面上用到的字。更新語詞資料後可執行 `python3 scripts/split-kai-font.py` 重新切分（需要 `pip install fonttools brotli`）。

## 自動測試

改版前在 `source/` 執行 `npm test`，會檢查練習方式序列、學習單產生與排版、描紅顏色等功能。
